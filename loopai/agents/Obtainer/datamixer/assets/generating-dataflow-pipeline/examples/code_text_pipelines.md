# Example: Code Text Generation and Cleaning Pipelines

## Use Case

Construct executable code SFT pairs from source code or seed descriptions, or
clean code pretraining text without LLM calls.

## Code-to-SFT

```text
raw_code -> CodeCodeToInstructionGenerator -> generated_instruction
  -> CodeInstructionToCodeGenerator -> generated_code
  -> CodeQualitySampleEvaluator
  -> CodeQualityScoreFilter
  -> CodeSandboxSampleEvaluator
```

## Seed-to-Code Dataset

```text
input -> CodeEnhancementInstructionGenerator -> generated_instruction
  -> CodeInstructionToCodeGenerator -> generated_code
  -> CodeQualitySampleEvaluator -> quality_score + quality_feedback
  -> CodeQualityScoreFilter -> quality_score_filter_label
  -> CodeSandboxSampleEvaluator
```

## CPU Code Pretraining Cleaning

```text
lines/text
  -> CodeAutoGeneratedFilter
  -> CodeLengthSampleFilter
  -> CodeTextCompositionFilter
  -> CodeEncodedDataFilter
  -> CodeDocumentQualityFilter
  -> CodeFileTypeContentFilter
  -> CodeGenericScoreFilter (when a score exists)
```

## Key Notes

- Sandbox execution is the correctness gate; LLM quality scores cannot replace it.
- Preserve language, file type, test output, and sandbox failure details.
- Never execute untrusted generated code outside `CodeSandboxSampleEvaluator`.
